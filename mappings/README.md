# Sample control mappings

These deliberately small files demonstrate Monday move 2: read the compliance metadata already present in scanner output, then **allow-list the mappings you agree with**. They are teaching samples, not complete framework crosswalks or audit advice.

Each sample contains no more than five requirements and records its source, license, retrieval date, and check IDs. Review both the control interpretation and every check before using a mapping in your environment.

Scan engine attribution: [Prowler 5.42.0 HIPAA and SOC 2 AWS compliance metadata](https://github.com/prowler-cloud/prowler/tree/5.42.0/prowler/compliance/aws) (Apache-2.0).
